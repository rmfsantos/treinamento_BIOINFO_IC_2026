GIT QUEST

A missao do bioinformata

FASE 1: O QUE E GIT?

Git e o seu SAVE GAME: ele guarda cada versao do seu progresso (codigo) para voce nunca perder o jogo.

Save Point

Registra cada mudanca, com data e autor.

Load Game

Volta a qualquer versao anterior do arquivo.

Co-op Mode

Varios jogadores editam sem sobrescrever o progresso dos outros.

FASE 2: CRIANDO SEU PERSONAGEM

1. Instalar (Ubuntu/Linux)

sudo apt update

sudo apt install git

2. Nomear seu avatar

git config --global user.name "Seu Nome"

git config --global user.email "voce@email.com"

So e feito uma vez por maquina, como criar sua ficha de personagem.

FASE 3: O COMBO ESSENCIAL

git add arquivo

Seleciona o item para o inventario (staging).

git commit -m "msg"

Confirma o save com uma descricao da fase.

git push origin master

Sincroniza seu progresso na nuvem (GitHub).

FASE 4: MAPA E INVENTARIO

  • git statusmostra o que mudou no seu mapa.
  • git rm / git mvdescarta ou renomeia itens do inventario.
  • git checkout arquivorecupera o save salvo na nuvem se voce falhar a missao.

GAME OVER se voce adicionar arquivos maiores que 50MB ao repositorio!

FASE 5: MULTIPLAYER

git clone

Baixa uma copia completa de um save de outro jogador.

git clone https://github.com/user/repo.git

git pull

Sincroniza seu jogo com as atualizacoes mais recentes do servidor.

git pull

BOSS FIGHT: GIT vs GITHUB

Nao sao o mesmo personagem! Git e o motor do jogo no seu PC; GitHub e o servidor online onde voce salva e joga com a galera.

GIT

  • Roda localmente no seu computador
  • Software de controle de versao
  • Funciona offline
  • Codigo aberto (Linux Foundation)

GITHUB

  • Plataforma na nuvem (site)
  • Hospeda repositorios Git
  • Precisa de internet
  • Adiciona PR, Issues e colaboracao

Resumo: voce usa Git para jogar sozinho; conecta ao GitHub para jogar em equipe.

POWER-UP: GIT NA BIOINFORMATICA

Sem controle de versao, pipelines de analise ficam bagunçados como "script_final_FINAL_v2.R". Git resolve isso.

Reprodutibilidade

Qualquer pessoa clona seu pipeline e reproduz sua analise exatamente.

Colaboracao em equipe

Alunos e orientadores trabalham no mesmo pipeline sem sobrescrever o trabalho um do outro.

Backup na nuvem

Scripts de QIIME2, DADA2 e R nunca se perdem se o computador falhar.

Ciencia aberta

Publicar codigo no GitHub aumenta visibilidade e credibilidade do artigo.

O QUE E UMA BRANCH?

Uma branch e uma fase bonus paralela: voce testa algo novo sem estragar o save principal do jogo.

git checkout -b equipe-N-bbduk

Cria e ja entra numa nova fase para sua equipe jogar sem afetar as demais.

O QUE E UM PULL REQUEST?

E como pedir a aprovacao do mestre do jogo antes de avancar de fase: voce propoe, o professor revisa e libera o proximo nivel.

  1. Clique em Compare and pull request apos o push.
  2. Escreva um titulo e descreva o que foi feito.
  3. Clique em Create pull request.
  4. Espere a aprovacao antes do merge.
